Notable AI mistakes & limitations

Things Claude got wrong that I caught/overrode:

  • EventBridge-rule misstep. For the NoSuchKey fix, Claude first proposed excluding transient uploads at the EventBridge rule before working out that a single rule can't AND a .jpg suffix with a NOT-query-temp/ prefix (array members OR). We pivoted to an in-Lambda guard, which is the fix that shipped.
  • CloudFormation DevOrigin gotcha. The first deploy silently reused the stack's stored DevOrigin value, so the CORS change didn't take. I had to redeploy passing the origins explicitly in --parameter-overrides. AI didn't anticipate CFN's stored-parameter reuse.

For honesty — these were teammates' bugs I diagnosed with Claude, not AI mistakes on my own work:

  • The tagger's full-item put_item overwriting my presign seed fields (a design issue in another teammate's Lambda; the fix is theirs).
  • The query-API storing COSMOS_KEY as a plaintext Lambda env var (a security issue on the query side that I flagged).

General limitation: Claude could not perform AWS deploys, Cognito console setup, or live browser/endpoint verification — I did all of that myself, and every piece of AI-written code was reviewed by me before it was merged.
