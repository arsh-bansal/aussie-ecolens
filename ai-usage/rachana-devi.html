How I Used AI

I used Claude primarily as a coding assistant rather than a decision-maker. Claude helped me generate initial boilerplate for handler modules and the JWKS-based auth middleware, which I then reviewed, adapted, and tested manually.

Claude made a number of mistakes I had to correct manually — most notably around Azure region configuration and endpoint routing — which required me to override its suggestions and apply the correct values myself.
